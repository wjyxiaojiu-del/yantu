# 小九科研工作台产品说明

## 产品定位

面向个人科研工作的 Windows 桌面工作台。目标不是堆叠管理页面，而是把“输入、推进、证据、记录、复盘和恢复”形成稳定闭环。

## 高频入口

1. 科研总览：判断当前整体状态。
2. 今日：确定唯一优先推进事项。
3. 任务推进：管理可执行下一步与 `S/A/B/C/L` 优先级。
4. 文献与证据：沉淀题录、阅读状态、摘要和证据笔记。
5. 每日记录与每周复盘：让真实过程产生可追溯反馈。
6. 研究地图：连接问题、假设、实验、证据、结论和论文。

## 产品边界

- 只面向个人本地使用，不建设导师/学生 SaaS。
- Windows 桌面端优先，不维护手机和平板专用布局。
- 网站内只连接本机 Codex Worker，不接入其他外部 Agent 或同步工具。
- 不把 Codex 推断自动升级为已经核验的科研证据。
- 不删除真实 SQLite 历史数据；结构调整必须提供兼容迁移和恢复验证。

## 成功标准

- 任意页面都能快速收集和全局检索。
- 每项重要结论都能追溯到任务、记录、文献或研究地图节点。
- Worker 离线、数据库异常或缺少快照时，页面能给出清晰状态。
- 空闲状态下不进行无意义高频轮询，保持较低内存与网络开销。
- 桌面关键流程无失败请求、无控制台错误，数据库完整性检查为 `ok`。
